# Repository Orientation

Use before the first substantial task or any cross-cutting refactor.

- Locate all AGENTS.md files and determine their scopes.
- Read product, architecture, primitives, contracts, implementation plan, and context pack.
- Inspect package scripts and existing tests.
- Produce a concise impact map: modules, files, contracts, tests, risks.
- Prefer existing patterns. Do not create a second architecture for the same concern.
