# Accuracy Audit

Use to approve analytical correctness.

- State the mathematical/statistical definition.
- Compare against an independent implementation or manually verified reference.
- Test nulls, duplicates, ties, zero variance, extreme magnitude, decimals, dates, locale, and empty datasets.
- Verify deterministic output and stable ordering.
- Measure numerical tolerance and document why it is acceptable.
- Verify explanation text matches actual factors.
- Record limitations and false-positive/false-negative risks.
